# AI智能租房决策助手

这是一个可直接部署到 GitHub Pages 的静态网站原型。

## 文件说明
- `index.html`：网站主页面
- `.nojekyll`：避免 GitHub Pages 使用 Jekyll 处理页面

## GitHub Pages 部署
1. 将本目录全部文件上传到仓库根目录。
2. 打开仓库 `Settings` → `Pages`。
3. 在 `Build and deployment` 中选择 `Deploy from a branch`。
4. 选择 `main` 分支和 `/ (root)` 目录并保存。
5. 等待 GitHub 完成部署。
